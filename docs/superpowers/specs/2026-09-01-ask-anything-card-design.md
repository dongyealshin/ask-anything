# 무엇이든 물어보세요 — 카드 뽑기 사이트 설계

- 작성일: 2026-09-01
- 사이트명: 무엇이든 물어보세요 (slug: ask-anything)
- 산출물: 단일 HTML 파일 1개 → Artifact로 퍼블리시하여 링크 공유

## 1. 목적

문구를 미리 작성한 사람이 링크 하나를 공유하면, 링크를 받은 사람이
카드를 뽑아 그 문구 중 하나를 무작위로 보게 되는 웹사이트.
가챠 뽑기 수준의 이모지·이펙트 연출을 갖춘다.

레퍼런스: 강원특별자치도의회 타로카드 이벤트 이미지
(카드 뒷면 3장을 펼쳐두고 하나를 선택하는 형태, 남색 배경 + 금색 타이포).

## 2. 확정된 요구사항

| 항목 | 결정 |
|---|---|
| 문구 저장·공유 | 서버 없이 URL 해시에 압축 인코딩 |
| 뽑기 방식 | 이용자가 카드를 직접 고르되 결과 문구는 랜덤 배정 |
| 재도전 | 무제한 다시 뽑기 |
| 등급 시스템 | 포함. 기본값 ★1(균등), 작성자가 원할 때만 상향 |
| 톤앤매너 | 남색 + 금색 타로풍 |
| 외부 의존성 | 없음 (CDN·이미지·사운드 파일 0개) |

## 3. 아키텍처

단일 HTML 파일에 두 화면을 담고 URL 해시로 분기한다.

| URL | 화면 | 역할 |
|---|---|---|
| `.../` | Builder | 제목·질문·문구 입력 → 공유 링크 생성 |
| `.../#d=<payload>` | Player | 카드 뽑기 → 결과 표시 |

해시 파싱에 실패하면 Builder로 폴백하고, "링크가 손상된 것 같아요" 안내를 띄운다.

### 3.1 모듈 경계

한 파일 안이지만 아래 단위로 분리해 서로 전역 상태를 공유하지 않는다.

| 모듈 | 책임 | 인터페이스 |
|---|---|---|
| `codec` | 데크 객체 ↔ URL 해시 문자열 변환 | `encode(deck) -> Promise<string>`, `decode(str) -> Promise<deck>` |
| `builder` | 입력 폼, 검증, 미리보기, 링크 복사 | `mount(root, initialDeck)` |
| `player` | 셔플·선택·개봉·결과 상태 기계 | `mount(root, deck)` |
| `fx` | 파티클, 플래시, 화면 흔들림 | `burst(emoji, rarity)`, `flash()`, `shake()` |
| `sfx` | WebAudio 합성 효과음, 진동 | `play(name)`, `setEnabled(bool)` |

`fx`와 `sfx`는 `player`에서만 호출되고 데이터 모델을 모른다.
`codec`은 DOM을 모른다.

## 4. 데이터 모델

```js
{
  t: "제목",                 // string, 1~40자
  q: "질문 한 줄",            // string, 0~80자
  n: 5,                      // 화면에 펼칠 카드 장수: 3 | 5 | 7
  c: [                       // 문구 목록, 1~30개
    { e: "🌊", m: "문구 내용", r: 1 }   // r: 등급 1|2|3
  ]
}
```

- `e` 이모지: 결과 연출 파티클에 사용. 미입력 시 기본값 `"✨"`.
- `m` 문구: 1~200자, 줄바꿈 허용.
- `r` 등급: 뽑힐 가중치와 이펙트 강도를 결정. 기본 1.

### 4.1 가중치

등급은 희소성이므로 높을수록 덜 나온다. 가중치는 `{1: 6, 2: 3, 3: 1}`.
전부 ★1이면 균등 추첨과 동일하다.

## 5. 링크 인코딩

```
deck --JSON.stringify--> UTF-8 bytes --deflate-raw--> base64url --> "#d=" + str
```

- 압축은 `CompressionStream('deflate-raw')` 사용. 미지원 브라우저에서는
  압축을 건너뛰고 인코딩만 한다.
- 압축 여부는 payload 첫 글자로 표시한다: `1` = 압축됨, `0` = 원문.
  디코더는 이 접두사를 보고 분기하므로 브라우저가 달라도 링크가 깨지지 않는다.
- base64url: `+` → `-`, `/` → `_`, `=` 제거.

**보안 성격**: 문구는 서버로 전송되지 않지만, 링크 소지자는 개발자도구로
전체 문구를 볼 수 있다. 기밀 정보용이 아님을 Builder 화면에 한 줄로 명시한다.

## 6. Builder 화면

- 제목 입력 / 질문 입력 / 카드 장수 선택(3·5·7)
- 문구 리스트: 행마다 [이모지][문구][★등급][삭제], "문구 추가" 버튼
- 우측(모바일은 하단) 실시간 카드 미리보기
- 하단 액션: `링크 만들기` → 링크 표시 + `복사` + `직접 테스트`
- 검증: 문구 0개면 링크 생성 불가, 제목 미입력 시 기본값 "무엇이든 물어보세요"

## 7. Player 화면 — 상태 기계

```
intro --섞기--> shuffle --애니메이션 종료--> spread
spread --카드 클릭--> focus --> reveal --> result
result --한 번 더--> shuffle
```

| 단계 | 연출 |
|---|---|
| intro | 제목·질문, 별이 흐르는 배경, "카드 섞기" 버튼 |
| shuffle | 카드가 한 곳에 겹쳤다가 부채꼴로 펼쳐짐 |
| spread | 뒷면 별빛 반짝임, 호버 시 카드가 떠오름 |
| focus | 선택 카드만 중앙으로, 나머지는 뒤로 물러나며 흐려짐 |
| reveal | 3D `rotateY` 뒤집기 + 방사형 플래시 + 테두리 발광 |
| result | 문구 타이핑 등장 + 이모지 파티클 분출 |

★3 결과에는 무지개 홀로그램 오버레이, 화면 흔들림, 이모지 비를 추가한다.

결과 화면 액션: `한 번 더 뽑기` / `링크 복사` / `나도 만들기`

## 8. 이펙트·사운드

- 파티클: `<canvas>` 위 requestAnimationFrame. 이모지를 텍스트로 그린다.
  개수는 등급별 60 / 90 / 140.
- 효과음: WebAudio 오실레이터 합성 (셔플 = 짧은 노이즈 버스트,
  개봉 = 상승 삼각파, ★3 = 화음). 외부 파일 없음.
  최초 클릭 이후에만 재생되므로 자동재생 정책에 걸리지 않는다.
- 우상단 사운드 토글, 기본 켜짐. 상태는 `localStorage`에 저장(실패해도 동작).
- 모바일: `navigator.vibrate` 존재 시 개봉 순간 짧게 진동.
- `prefers-reduced-motion` 사용자에게는 파티클·흔들림을 끄고 페이드로 대체한다.

## 9. 반응형·접근성

- 375px 폭 기준으로 카드 배치가 깨지지 않아야 한다. 카드 7장은 모바일에서
  2줄로 배치한다.
- 카드는 `<button>`으로 만들어 키보드 탐색·엔터 선택이 가능해야 한다.
- 라이트/다크 어느 테마에서도 남색 배경을 명시적으로 칠한다.

## 10. 검증 항목

완료 선언 전에 아래를 실제로 실행하고 결과를 보여준다.

1. 링크 왕복: 인코딩 → 디코딩 결과가 원본 객체와 일치
2. 긴 문구(200자) · 줄바꿈 · 이모지 포함 입력
3. 문구가 1개뿐일 때 정상 동작
4. 모바일 375px 폭 레이아웃
5. 손상된 해시(`#d=zzzz`)로 접속 시 Builder 폴백 + 안내
6. `CompressionStream` 미지원 경로(폴백 강제) 인코딩·디코딩
